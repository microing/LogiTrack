# LogiTrack

Logistics & Shipment Tracking Platform

## Overview

LogiTrack is an API-first, event-driven logistics and shipment
tracking platform developed using Java Spring Boot, React,
PostgreSQL, Kafka, Redis, and Docker.

## Architecture

The system consists of:

- React Web Application
- API Gateway
- Identity Service
- Shipment Service
- Tracking Service
- Delivery Service
- Notification Service
- Reporting Service

## Technology Stack
